## 📚 Core Concepts & Topics Covered

- **Classes & Objects:** Constructors (`__init__`), instance attributes, and methods.
- **Encapsulation:** Private/protected attributes, getters, setters, and data validation.
- **Inheritance & Polymorphism:** Base classes, derived subclasses, and method overriding.
- **Exception Handling:** Built-in exceptions (`ValueError`) and custom domain exceptions.
- **Graphical User Interfaces (GUI):** Event-driven desktop apps built with `Tkinter`.
- **Quality Assurance (QA):** Automated unit testing, fixtures, and parametrized tests using `pytest`.
